# ABQARI MATH — عبقري رياضيات

تطبيق Flutter مستقل ضمن مستودع ABQARI. يُبنى ويُصدر دون الاعتماد على التطبيق الآخر.

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug            # Android
flutter build ios --debug --no-codesign   # iOS (على macOS)
```

المعرّف الحالي مولَّد آليًا (`com.abqari.abqari_math`) وليس نهائيًا؛ يُحسم قبل إعداد المتجرين.
