# ABQARI – عبقري

منصة رياضيات عامة ثنائية اللغة، تتكون من تطبيقين مستقلين يُبنيان من مستودع واحد:

- **ABQARI EDU**: تعلّم الرياضيات عبر دروس ومسارات ومهارات وتدريبات واختبارات، دون الارتباط بأي دولة أو منهج أو كتاب مدرسي.
- **ABQARI MATH**: مساحة رياضيات عامة للحل والتحقق والاستكشاف من الأساسيات إلى الرياضيات المتقدمة.

## قرارات المنتج
- تطبيقان مستقلان في الإصدار والتوزيع.
- مستودع برمجي واحد ومكونات مشتركة.
- العربية والإنجليزية منذ البداية (RTL/LTR).
- الأدوار: طالب، معلم، مدير.
- تصنيف المحتوى حسب المجال، والموضوع، والمستوى، والمتطلبات السابقة، والصعوبة؛ وليس حسب دولة أو منهج.

## بنية المستودع
```text
apps/
  abqari_edu/       # تطبيق التعلم
  abqari_math/      # تطبيق الرياضيات العام
packages/           # واجهات وخدمات ومحركات مشتركة
backend/            # API وقاعدة البيانات وخدمات الذكاء الاصطناعي
admin/              # لوحة الإدارة
docs/               # قرارات ومعمارية وخطة
tests/              # اختبارات مشتركة وتكاملية
```

## الحالة الحالية
هذا **هيكل بداية** وليس إصداراً إنتاجياً. لم يتم ربط Supabase أو أي مزود ذكاء اصطناعي، ولم تُنشأ مفاتيح أو حسابات خارجية. يجب تشغيل الاختبارات والتحقق من البناء محلياً قبل اعتبار أي ميزة مكتملة.

## البدء
1. ثبّت Flutter وDart بإصدارات مستقرة متوافقة.
2. افتح كل مجلد تطبيق وشغّل `flutter pub get`.
3. شغّل `flutter analyze` ثم `flutter test`.
4. لا تضف أسرار API إلى تطبيقات Flutter؛ اجعلها في الخادم فقط.
5. راجع `docs/ARCHITECTURE.md` و`docs/ROADMAP.md` قبل توسيع البنية.
