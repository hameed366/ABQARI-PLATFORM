# خارطة التنفيذ

## المرحلة 0 — تثبيت الأساس
- مراجعة بنية المستودع وأسماء الحزم.
- تشغيل Flutter analyze/test لكل تطبيق.
- اعتماد نظام الترجمة واتجاه RTL/LTR.
- إعداد CI للتحليل والاختبارات.

## المرحلة 1 — نواة مشتركة
- تصميم النظام البصري والمكونات المشتركة.
- تسجيل الدخول والأدوار (بعد إعداد backend فعلي).
- محرر إدخال رياضي يدعم العربية والإنجليزية.
- نموذج بيانات المجالات والموضوعات والمهارات.

## المرحلة 2 — ABQARI MATH
- العمليات الأساسية والجبر والمعادلات.
- الحل خطوة بخطوة مع تحقق مستقل.
- الرسوم البيانية والهندسة الأساسية.
- سجل المسائل والمفضلة.

## المرحلة 3 — ABQARI EDU
- مسارات تعلم عامة حسب المستوى والمهارة.
- دروس قصيرة وأمثلة وتدريبات.
- اختبارات وتغذية راجعة.
- لوحة متابعة الطالب والمعلم.

## المرحلة 4 — الذكاء الاصطناعي والتوسع
- مساعد تعليمي عبر API آمن.
- OCR للصور الرياضية بعد اختبار الدقة.
- التفاضل والتكامل والإحصاء والجبر الخطي وغيرها.
- اختبارات أداء وإتاحة وأمان قبل الإطلاق.

كل مرحلة تتطلب معايير قبول واختبارات موثقة. لا تنتقل إلى المرحلة التالية لمجرد إنشاء واجهات شكلية.
