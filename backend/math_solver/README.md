# محرك الرياضيات — `abqari_solver`

مكتبة Python تستقبل مسألة مكتوبة نصًا وتعيد: ما فُهم منها، الحل، خطواته، ودرجة التحقق منه.
ليست خدمة شبكية بعد؛ واجهة API تُبنى فوقها في المرحلة 8.

```python
from abqari_solver import solve
solve("حل: ٢س + ٣ = ٧")
solve("(x+1)^2", task="expand")
```

## المراحل الداخلية
1. `normalize.py` — توحيد الكتابة: الأرقام الهندية، س/ص/ع، جا/جتا/ظا/لو/لط/جذر، × ÷ √ ² π، وكلمة الأمر (حل، بسّط، فك، حلل، اشتق، تكامل، احسب).
2. `parser.py` — محلل مكتوب يدويًا يبني شجرة للعبارة. **لا يُنفَّذ أي نص من المستخدم** (لا `eval`).
3. `latex.py` — إعادة عرض ما فُهم كما كُتب، ليؤكده المستخدم.
4. `to_sympy.py` و`engine.py` — الحل الرمزي بـSymPy.
5. `verify.py` — تحقق مستقل لا يشارك SymPy الرمزي أي كود: حساب كسور مضبوط بأعداد Python الصحيحة، وتقييم عددي بـmpmath بدقة 40 رقمًا، كلاهما يقرأ شجرة ما كتبه المستخدم.

## حالة التحقق
| الحالة | المعنى |
|---|---|
| `verified` | كل الفحوص المستقلة الممكنة نجحت |
| `partial` | لم يتعارض شيء، لكن فحصًا لم يمكن إجراؤه (مثلًا: إثبات عدم وجود حلول أخرى لمعادلة غير كثيرة حدود) |
| `failed` | فحص مستقل تعارض مع الناتج — لا يُعرض على أنه صحيح |

## المدعوم الآن
الحساب والكسور والجذور والأسس، قيم الدوال المثلثية واللوغاريتمية، التحقق من صحة عبارة عددية، المعادلات الخطية والتربيعية (بخطوات)، كثيرات الحدود الأعلى والمعادلات الأخرى بمتغير واحد (دون خطوات)، التبسيط والفك والتحليل، الاشتقاق والتكامل غير المحدد.

## غير المدعوم بعد
المتباينات، أكثر من متغير، أنظمة المعادلات، المصفوفات، النهايات، التكامل المحدد، المعادلات المثلثية الدورية، الأعداد المركبة، المسائل اللفظية (تحتاج المساعد الذكي)، وخطوات الاشتقاق والتكامل.

## قيود معروفة
- `log` للأساس عشرة و`ln` للطبيعي.
- تكامل `1/x` يُعاد `log(x)` لا `ln|x|`.
- `1/2x` تُقرأ `(1/2)·x`.
- لا مهلة زمنية للحساب بعد؛ تُضاف مع طبقة API.
