# abqari_ui

الهوية البصرية المشتركة لتطبيقَي ABQARI. لا تحتوي نصوصًا؛ أي نص ظاهر يمرره التطبيق.

- `AbqariColors` — كحلي، أزرق، بنفسجي، ولمسة مضيئة.
- `AbqariTheme.light/dark(product)` — سمة واحدة للتطبيقين؛ اللون الأساسي أزرق في EDU وبنفسجي في MATH.
- `ThemeModeController` و`ThemeModeButton` — تلقائي / فاتح / داكن، مع حفظ الاختيار.
- `AbqariLogo` — الشعار مرسومًا بالكود (لا صور).
- `FeatureCard` — بطاقة وصفية غير قابلة للضغط.

التطبيقان لا يعرّفان ألوانًا خاصة بهما؛ كل لون يأتي من هنا.
