# abqari_formula — عرض الرياضيات

يرسم عبارات المحرك بأحد ترميزين، حسب لغة الواجهة:

| | العربي | اللاتيني |
|---|---|---|
| الاتجاه | من اليمين إلى اليسار | من اليسار إلى اليمين |
| الأرقام | ٠١٢٣٤٥٦٧٨٩، والفاصلة العشرية ٫ | 0123456789 |
| الأس | أعلى يسار الأساس | أعلى يمين الأساس |
| الجذر | معكوس | عادي |
| المتغيرات | س ص ع ن، أ ب جـ للمعاملات | x y z n، a b c |
| الدوال | جا جتا ظا لو لط | sin cos tan log ln |
| الثوابت | π، هـ | π، e |

`MathView.expression` و`MathView.statement` و`MathView.chain` لكل من العبارة والعلاقة وسطر خطوات الحل.
`mathPlainText` يعطي النص الخطي نفسه لقارئ الشاشة وللنسخ.
