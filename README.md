# ABQARI – عبقري

منصة رياضيات عامة ثنائية اللغة، تتكون من تطبيقين مستقلين يُبنيان من مستودع واحد:

- **ABQARI EDU**: تعلّم الرياضيات عبر دروس ومسارات ومهارات وتدريبات واختبارات، دون الارتباط بأي دولة أو منهج أو كتاب مدرسي.
- **ABQARI MATH**: مساحة رياضيات عامة للحل والتحقق والاستكشاف من الأساسيات إلى الرياضيات المتقدمة.

## قرارات المنتج
- تطبيقان مستقلان في الإصدار والتوزيع.
- مستودع برمجي واحد ومكونات مشتركة.
- العربية والإنجليزية منذ البداية (RTL/LTR).
- الأدوار: طالب، معلم، مدير.
- تصنيف المحتوى حسب المجال، والموضوع، والمستوى، والمتطلبات السابقة، والصعوبة؛ وليس حسب دولة أو منهج.

## بنية المستودع
الموجود حاليًا:
```text
apps/
  abqari_edu/       # تطبيق التعلم
  abqari_math/      # تطبيق الرياضيات العام
packages/
  localization/     # اللغتان، التبديل الفوري، حفظ الاختيار، الأرقام
  shared_ui/        # الألوان، الفاتح والداكن، الشعار، مكونات مشتركة
  math_engine/      # نواة المحرك على الجهاز (Dart)
  math_view/        # عرض الرياضيات بالترميز العربي أو اللاتيني
  engine_bridge/    # تشغيل المحرك الكامل (Python) داخل التطبيق
backend/
  database/         # هجرات PostgreSQL
  math_solver/      # محرك الرياضيات (Python/SymPy) مع تحقق مستقل
docs/               # قرارات ومعمارية وخطة وتقارير المراحل
tests/              # اختبارات القاعدة ونظافة المستودع
.github/workflows/  # CI: الخلفية + كل تطبيق على Android وiOS
```
يُضاف لاحقًا، كلٌّ مع تنفيذه واختباراته: بقية الحزم، `backend/api`، `backend/ai`، `admin/web_dashboard`.

## الحالة الحالية
**هيكل بداية** وليس إصدارًا إنتاجيًا. اكتملت المراحل 1–6 — راجع تقارير المراحل في `docs/`. التطبيقان بالعربية والإنجليزية مع تبديل فوري، وبوضعين فاتح وداكن. في ABQARI MATH شاشة حل تعمل على الجهاز، بنواة سريعة ومحرك كامل (Python + SymPy) مضمّن في التطبيق. التطبيقان يُحلَّلان ويُختبران ويُبنيان (debug، دون توقيع) لأندرويد وiOS في CI. لم يُشغَّلا على جهاز بعد، ولا توجد ملفات IPA/APK للنشر. لم يُربط أي خادم أو مصادقة أو مزود ذكاء اصطناعي، ولم يُطبَّق مخطط القاعدة على أي قاعدة حية.

## تشغيل التطبيقين
داخل كل تطبيق:

```bash
cd apps/abqari_edu      # أو apps/abqari_math
flutter pub get
flutter analyze
flutter test
flutter run
```

## بناء ABQARI MATH مع المحرك الكامل
قبل `flutter build`، غلّف المحرك مع Python (يحتاج إنترنت لتنزيل SymPy):

```bash
tools/package_python_engine.sh Android   # أو iOS على macOS
```

متغيرات `SERIOUS_PYTHON_*` نفسها يجب أن تكون معرّفة أثناء البناء؛ راجع `.github/workflows/ci.yml`.

## تشغيل الاختبارات المتاحة
يتطلب Python 3.11+ مع pytest (و`pip install -r backend/math_solver/requirements.txt` لاختبارات المحرك)، وخادم PostgreSQL 14+ عبر متغيرات libpq (`PGHOST`، `PGUSER`…) بصلاحية superuser. تُنشأ قاعدة مؤقتة وتُحذف تلقائيًا.

```bash
python -m pytest
```

دون خادم PostgreSQL تُتخطّى اختبارات القاعدة (skipped) ولا تُحسب ناجحة.
