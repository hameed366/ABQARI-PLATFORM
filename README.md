# ABQARI – عبقري

منصة رياضيات عامة ثنائية اللغة، تتكون من تطبيقين مستقلين يُبنيان من مستودع واحد:

- **ABQARI EDU**: تعلّم الرياضيات عبر دروس ومسارات ومهارات وتدريبات واختبارات، دون الارتباط بأي دولة أو منهج أو كتاب مدرسي.
- **ABQARI MATH**: مساحة رياضيات عامة للحل والتحقق والاستكشاف من الأساسيات إلى الرياضيات المتقدمة.

## قرارات المنتج
- تطبيقان مستقلان في الإصدار والتوزيع.
- مستودع برمجي واحد ومكونات مشتركة.
- العربية والإنجليزية منذ البداية (RTL/LTR).
- الأدوار: طالب، معلم، مدير.
- تصنيف المحتوى حسب المجال، والموضوع، والمستوى، والمتطلبات السابقة، والصعوبة؛ وليس حسب دولة أو منهج.

## بنية المستودع
الموجود حاليًا:
```text
apps/
  abqari_edu/       # تطبيق التعلم
  abqari_math/      # تطبيق الرياضيات العام
backend/database/   # هجرات PostgreSQL
docs/               # قرارات ومعمارية وخطة وتقارير المراحل
tests/              # اختبارات القاعدة ونظافة المستودع
.github/workflows/  # CI: الخلفية + كل تطبيق على Android وiOS
```
يُضاف لاحقًا، كلٌّ مع تنفيذه واختباراته: `packages/`، `backend/api`، `backend/ai`، `backend/math_solver`، `admin/web_dashboard`.

## الحالة الحالية
**هيكل بداية** وليس إصدارًا إنتاجيًا. اكتملت المرحلتان 1 و2 — راجع `docs/PHASE1_AUDIT.md` و`docs/PHASE2_REPORT.md`. التطبيقان يُحلَّلان ويُختبران ويُبنيان (debug، دون توقيع) لأندرويد وiOS في CI. لم يُشغَّلا على جهاز بعد، ولا توجد ملفات IPA/APK للنشر. لم يُربط أي خادم أو مصادقة أو مزود ذكاء اصطناعي، ولم يُطبَّق مخطط القاعدة على أي قاعدة حية.

## تشغيل التطبيقين
داخل كل تطبيق:

```bash
cd apps/abqari_edu      # أو apps/abqari_math
flutter pub get
flutter analyze
flutter test
flutter run
```

## تشغيل الاختبارات المتاحة
يتطلب Python 3.11+ مع pytest، وخادم PostgreSQL 14+ عبر متغيرات libpq (`PGHOST`، `PGUSER`…) بصلاحية superuser. تُنشأ قاعدة مؤقتة وتُحذف تلقائيًا.

```bash
python -m pytest
```

دون خادم PostgreSQL تُتخطّى اختبارات القاعدة (skipped) ولا تُحسب ناجحة.
