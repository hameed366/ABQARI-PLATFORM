# abqari_bridge — المحرك الكامل داخل التطبيق

يشغّل محرك Python/SymPy (`backend/math_solver`) داخل التطبيق نفسه عبر serious_python،
ويحوّل ردوده إلى أنواع النواة (`SolveResult`، `Node`) لتُعرض بالترميز العربي أو اللاتيني نفسه.

- المحرك خادم صغير على `127.0.0.1` فقط، برمز سري جديد في كل تشغيل؛ لا تصل إليه التطبيقات الأخرى.
- يبدأ عند أول مسألة تحتاجه، لا عند فتح التطبيق.
- إن تعذّر تشغيله أو تأخر، يُرمى `FullEngineUnavailable` ويبقى رد النواة كما هو.
