# abqari_engine — نواة المحرك على الجهاز

نواة محرك الرياضيات بلغة Dart، تعمل داخل التطبيق دون خادم ودون إنترنت.
تقرأ المسألة بالعربية أو الإنجليزية، تحلها حلًا مضبوطًا، وتتحقق من الناتج بطريقة مستقلة.

- **الحساب** بالكسور المضبوطة والجذور التربيعية (من حقل واحد √m).
- **صحة عبارة** عددية (=، <، ≤ …) بمقارنة مضبوطة.
- **معادلات كثيرات الحدود بمتغير واحد**: الخطية والتربيعية بخطوات؛ الأعلى بالجذور النسبية مع عدّ الجذور الحقيقية بنظرية شتورم لإثبات أنه لم يُغفل حل.
- **تبسيط وفك وتحليل** كثيرات الحدود بمتغير واحد.
- **اشتقاق وتكامل** كثيرات الحدود.

ما يتجاوز ذلك (الدوال المثلثية واللوغاريتمية، أكثر من متغير، الجذور غير التربيعية…) يعود بحالة
`unsupported` ورمز `needs_full_engine`، ولا يخمّن. هذه المسائل للمحرك الكامل (`backend/math_solver`، Python/SymPy) عند توفر خادم.

نفس منطق القراءة والتحقق في محرك Python، والنواتان تُختبران على مجموعة المسائل المرجعية نفسها (`tests/math/reference_problems.json`).
